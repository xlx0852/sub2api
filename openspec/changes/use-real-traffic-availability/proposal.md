# Change: 首页可用率改用真实业务请求

## Why
当前首页可用率依赖主动渠道探测。探测请求会产生额外成本，其凭据、模型和网络路径也不能代表用户的真实调用体验；在没有配置探测任务时页面只能显示空样本。

## What Changes
- 新增真实业务流量可用率聚合接口，合并成功使用记录与终态失败记录，并按请求 ID 去重。
- 管理员首页统计全站真实请求；普通用户首页只统计当前用户自己的请求。
- 支持按平台切换统计范围，分别查看 OpenAI、Claude、Grok、Kimi 或全站汇总。
- 默认统计最近 24 小时，按 10 分钟聚合状态方格。
- 成功率按真实成功请求除以全部终态请求计算，平均响应只使用成功请求实际耗时。
- 状态阈值为：成功率不低于 99% 为健康，95% 至 99% 为轻微波动，低于 95% 为需要关注，无请求为灰色。
- 主动探测只在连续无真实流量时作为补充信号，且不进入首页成功率、平均响应和样本数。

## Impact
- Affected specs: `traffic-availability`
- Affected code: 使用/错误日志聚合仓储、用户和管理员统计接口、首页可用率组件、测试
